# Library

Original patterns authored here. Everything in this folder is MIT licensed and may be reused in any project with attribution.

This tier starts empty on purpose. A pattern earns a place here after it has been built and tested in a real project, not invented to fill a catalog.

To add one, copy `template/entry.md` into `library/<id>/entry.md`, set `tier: pattern`, `license: MIT`, `rights: own`, and include the source files.
