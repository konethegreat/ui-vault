# What it is

A full-screen dark hero. A WebGL2 fragment shader paints a drifting cloud and light field, and the marketing content sits above it with staggered fade-ins and warm gradient headings.

# Why it is interesting

- The shader is procedural, with no textures, so it stays sharp at any size and adds no image payload.
- The copy hierarchy is complete: badge, two-line headline, subtitle, primary and secondary action.
- The reveal is staged at 0.2, 0.4, 0.6 and 0.8 seconds, which reads as calm rather than slow.
- The palette holds together: orange, yellow and amber against black.

# What to borrow

- The staged reveal timing for any dense hero.
- The single canvas behind absolutely positioned content.
- The translucent badge with a border and backdrop blur.
- The two-line headline with a gradient clip and a second, warmer gradient on line two.

# Defects if reused as is

- The file has two default exports, the component and a demo, so it does not compile as one module.
- Uses `<style jsx>`, which requires styled-jsx and ties the component to Next.js.
- The renderer and pointer handler classes are declared inside the hook and are rebuilt on every render.
- Dynamic Tailwind classes such as `text-${color}-300` are never generated by the compiler.
- The viewport applies the device pixel ratio twice, once in the canvas size and again in the viewport call.
- Pointer, move and touch uniforms are wired up but the shader ignores them, so the background is not actually interactive.
- No reduced-motion handling. The animation runs continuously.
- `useRef<number>()` without an initial value fails under current React type definitions.
