# What it is

A large collection of animated React components: text effects, backgrounds, cursor effects, micro-interactions and full components. Installed as source through the shadcn CLI or jsrepo.

# Use it

```bash
npx shadcn@latest add @react-bits/SplitText-TS-TW
npx jsrepo@latest add https://reactbits.dev/r/SplitText-TS-TW
```

The suffix is two choices: language (JS or TS) then styling (CSS or TW). The example above is TypeScript with Tailwind.
